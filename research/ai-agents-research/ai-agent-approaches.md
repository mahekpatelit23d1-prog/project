## AI-Agent Research for Our Project

The project uses multiple team members working on different AI and machine-learning components. AI-agent research should therefore focus on how specialized agents can communicate and divide responsibilities.

Potential roles may include:

- Research agent
- Data analysis agent
- Prediction/model agent
- Information retrieval agent
- Report or explanation agent
