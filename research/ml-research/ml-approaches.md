## Dataset-Specific Research

The current project dataset uses 'Success' as a binary target variable with values 0 & 1. Therefore, classification algorithms are more appropriate than regression algorithms for the current prediction task.

Potential approaches to evaluate include Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting.

The final model choice should be based on model evaluation results and the team's technical decisions.
